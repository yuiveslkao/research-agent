# Benchmark: Example 1 of arXiv:2305.05127v4 (accelerated flows for functionals of measures)

Source: K. Tanaka, *Accelerated gradient descent method for functionals of probability measures by
new convexity and smoothness based on transport maps* (topic 1: optimization of measures).
I read the extracted text only: figures, and the last part of the proof of Theorem 5.5, were not visible to me.

## Why this one

- It has explicit finite-n inequalities inside the proofs (Lyapunov monotonicity), not just `O(1/n)`
  statements, so `falsify` has real targets, including intermediate proof steps.
- Example 1 is exactly solvable in structure: all maps are affine, so a Float64 particle run can be
  cross-checked against a 60-digit independent implementation.
- It needs no special functions, no GPU and no optimizer, so failures point at the pipeline, not the math.
- The DE/Sinc files stay in the repo as the harness self-test (`known_answer`), where high precision matters most.

## Setting (F1 on R)

`F1 = W + V`, `W(μ) = ½∬(x−y)² dμdμ`, `V(μ) = ∫(x−1)² dμ`. For an empirical measure with mean `m` and
variance `σ²`: `F1 = 2σ² + (m−1)²`, minimizer `δ_1`, gradient `G(x) = 2(x−m) + 2(x−1)`.

- **Gradient descent** (3.4): `X_{n+1} = X_n − γ G(X_n)`, `γ = (3/2)τ`.
- **Accelerated** (3.12)–(3.14) with (5.4)–(5.5), `1/L → τ`: `a_n = (n+1)(n+2)τ/16`,
  `X_{n+1} = Y_n + ((a_{n+1}−a_n)/a_{n+1})(Z_n − Y_n)`, `Z_{n+1} = Z_n − (a_{n+1}−a_n)G(X_{n+1})`,
  `Y_{n+1} = X_{n+1} − τ G(X_{n+1})`.
- `D(μ_n, μ*) = ½ E|X_n − 1|²`, `τ ∈ {0.0025, 0.005, 0.01}` (paper), `L = 4`.
- The paper does not state `μ0` in the text I read. The reference uses 20 equispaced points on `[-1, 3]`.

## Executable statements (all finite, all falsifiable)

| Id | Statement | Source |
|---|---|---|
| S1 | GD: `L_n := nγ(F(μ_n)−F*) + D(μ_n, μ*)` is nonincreasing for `n ≥ 1` when `γ ≤ 3/(2L)` | proof of Thm 5.3, (A.23)–(A.28) |
| S2 | GD: `F(μ_n) − F* ≤ [γ(F(μ_1)−F*) + D(μ_1, μ*)]/(nγ)` | end of proof of Thm 5.3 |
| S3 | ACC: `L^ac_n := a_n(F(ν_n)−F*) + D(ξ_n, μ*)` is nonincreasing | proof of Thm 5.5 (A.35)–(A.39); the conclusion is my reading, the proof text was cut off in my copy |
| S4 | ACC: `F(ν_n) − F* ≤ L^ac_0 / a_n`, which is `O(1/n²)` | consequence of S3 |
| S5 | Constants: `F1` is transport L-smooth with `L = 4` | Sec. 6.1, via Thms 4.7–4.8 |

`margin` for S1/S3 is `L_n − L_{n+1}`, and for S2/S4 it is bound minus value. Domain: `τ`, `n`, and `μ0`
(number of points, spread). Values must be computed at high precision, because `F1` decays below
`1e-32` in double precision (the variance floor, from the roundoff of `x_i ≈ 1`).

## What the mpmath prototype found (60 digits, 20 points; not Julia)

- S1–S4 hold for `τ ∈ {0.0025, 0.005, 0.01}` and for `τ = 1/L` under the `½` convention.
- They fail for `τ = 2/L` (divergence), as expected from `γ ≤ 3/(2L)`.
- **Notation issue (S5).** Eq. (6.3) prints `W1 = ∬(x−y)²` without the `½` of (2.4). Read literally,
  `F1 = 3σ² + (m−1)²` and the true smoothness constant is 6, not 4. Then `τ = 1/4` (`γ = 0.375 = 3/(2·4)`)
  breaks S1 and S2 for gradient descent (checked at `τ = 0.2` and `0.25`), while the stated experiments
  (`τ ≤ 0.01`) are unaffected. Which reading was intended is a question for the author.
- In this setting the dynamics are linear, so plain GD converges geometrically. The `O(1/n)` and `O(1/n²)`
  bounds are valid but far from tight here. At `τ = 0.01`, `n = 100`: `F_GD ≈ 1.2e-5`, `F_ACC ≈ 4.2e-5`,
  which matches the paper's remark that the plain method leads at first.

Reference values for a future Julia implementation: `workspace/library/testdata/ex1_reference.toml`,
generated by `workspace/reference/measure_flow_ex1.py`.

## Suggested Phase 0 stages on this benchmark

1. Port check: Julia matches `ex1_reference.toml` to about 25 digits (`F`, `lyap` at `n = 10, 100, 1000`).
2. Reproduction: Float64 and BigFloat runs of both flows for the three `τ`, saving `F(μ_n)` curves.
3. High-precision verification: Float64 vs BigFloat agreement until the Float64 floor, and saturation flagged.
4. Rerun: bitwise (no randomness, since `μ0` is deterministic).
5. Falsification: S1–S4 over `τ ∈ (0, 2/L)`, `n`, and `μ0`. Expected: violations only where `τ` exceeds the theorem's range. The S5 check is a deliberate probe of the notation issue above.
